# Pont NVIDIA FrameView

Ce dossier contient le petit pont natif utilisé par FlexHub pour lire la puissance et la température du package CPU via le SDK FrameView.

`Build-FrameViewBridge.ps1` nécessite Microsoft C++ Build Tools et une installation locale du SDK NVIDIA FrameView. Le SDK et ses bibliothèques restent la propriété de NVIDIA et ne sont pas redistribués par FlexHub.
