# PawnIO

`PawnIO_setup.exe` est l’installateur officiel signé de PawnIO 2.2.0. FlexHub l’utilise au premier lancement administrateur pour permettre à LibreHardwareMonitor de lire directement les capteurs CPU, sans dépendre de NVIDIA FrameView.

- Versions officielles : https://github.com/namazso/PawnIO.Setup/releases
